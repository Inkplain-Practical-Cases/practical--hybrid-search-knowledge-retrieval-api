# Hybrid Search & Knowledge Retrieval API

Junior FDE hybrid retrieval service with BM25/keyword and vector ranking, tenant isolation, metadata filtering, reranking, citations and evaluation.

An Inkplain practical case: a real project built step by step.

## How this repository works

Every step of the lesson has its own branch, and each one contains all steps up to it:

```bash
git clone https://github.com/Inkplain-Practical-Cases/practical--hybrid-search-knowledge-retrieval-api.git
cd practical--hybrid-search-knowledge-retrieval-api
git branch -r            # list the step branches
git checkout step-01-…   # code after step 1
```

`main` holds the final, complete version.
